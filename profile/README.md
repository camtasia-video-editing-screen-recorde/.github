## Troubleshooting Common Issues

Install issues? Run the installer as administrator, close background capture tools, and confirm the OS build is still supported.  
Performance problems? Lower the preview resolution, move the project to an SSD, and close browser tabs during long recordings.  
License/activation? Sign in with the account that owns the seat and check that the license is not already active on another machine.  
Compatibility? Keep the app updated for the latest codec support and test older project files on the current release before editing.  
Update failures? Restart the machine, disable aggressive antivirus scanning during setup, and reinstall from a fresh download.
